# Data Science Portfolio

Source files for my GitHub Pages portfolio.

**Live site:** <https://zhoujiin116-cmd.github.io/data-science-portfolio/>

**Featured project:** [Macau's Post-Pandemic Tourism Recovery](https://github.com/zhoujiin116-cmd/data-science-project)

## Contents

- `index.md` - portfolio homepage (name, introduction, skills, project showcase)
- `assets/` - figures used on the homepage
- `_config.yml` - GitHub Pages / Jekyll theme configuration

## Publishing

The site is published with GitHub Pages from the `main` branch and the `/ (root)` folder. To update it, edit `index.md`, commit, and push to `main`; GitHub Pages rebuilds automatically.

## Data and privacy

The portfolio contains no student ID, personal contact details, passwords, API keys, or restricted datasets. The featured project uses public aggregate statistics and documents its sources and limitations in its README.
